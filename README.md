# svadba

Plánovač zasadacieho poriadku pre jeden dlhý stôl — jedna statická HTML stránka, bez závislostí a bez backendu.

**Živá verzia:** https://peter-gabris.github.io/svadba/

Rozloženie sa ukladá do `localStorage` prehliadača. Medzi zariadeniami sa prenáša
kódom plánu (tlačidlo *Zdieľať*), prípadne cez `#ZP1…` v adrese.
